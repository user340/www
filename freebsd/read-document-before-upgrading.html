アップグレードはドキュメントを読んでから——14.3から15.0へのアップグレードを例に

2026年4月5日 初稿

結論

まずは関連するドキュメントを読んでからアップグレードすること。

発端と問題

FreeBSD 15.0がリリースされていることに気がついたのでfreebsd-updateをなんの考えなしに実行したところ、再起動後にこのようなエラーが出るようになりました。

ld-elf.so.1: Shared object "libsys.so.7" not found, required by "libc.so.7"

どうやらlibcにリンクしているバイナリを実行するとlibsys.so.7が存在していないことでエラーになってしまうようです。

解決策

任意のFTPサーバからFreeBSD 15.0のbase.txzを取得し、その中からlib/libsys.so.7をUSBメモリなどの外部ストレージにコピーします。FreeBSDマシンにそのストレージを接続し、libsys.so.7を/libへコピーします。USBメモリであれば以下のコマンドを実行してマウントできます。

/rescure/mount_msdos /dev/da0 /mnt

その後おそらく中断されていたであろうインストールプロセスをやり直します。

freebsd-update -r 15.0 fetch -F
freebsd-update install

どうすればよかったのか

アップグレードのようなクリティカルな操作については公式にドキュメントが用意されているものなのでそれを熟読したうえでおこなえばよかったのです。

FreeBSD 15.0-RELEASE Installation Instructions

This step is essential, as upgrading to 15.0-RELEASE without applying the FreeBSD-EN-25:18.freebsd-update errata update will result in an inoperative system!
